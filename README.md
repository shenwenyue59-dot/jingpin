# 年度品牌雷达

一个用于查看美妆、婴童洗护品牌年度增长和新锐黑马候选的轻量网页工具。

当前快照对比两个滚动年度窗口：

- 上一年度：2024-08-14 至 2025-08-13
- 本年度：2025-08-14 至 2026-08-13

数据来自飞瓜实数品牌榜接口。由于后台自定义榜单有时间范围限制，抓取脚本会按不超过 180 天的区间分段拉取，再汇总为年度对比。

## 在线访问

仓库启用 GitHub Pages 后，建议选择 `docs/` 目录作为发布来源。`docs/` 中已经包含静态网页和本次数据快照，别人无需登录后台即可查看。

## 本地运行

```bash
npm start
```

打开：

```text
http://localhost:5177/
```

## 重新同步数据

本地同步需要先打开带调试端口的浏览器，并保持飞瓜实数账号已登录，然后运行：

```bash
node work/fetch-feigua-brand-rank.js
```

同步完成后，将 `data/brand-radar-data.json` 复制到：

```text
public/data/brand-radar-data.json
docs/data/brand-radar-data.json
```

再提交到 GitHub，即可更新在线版数据。

## 口径说明

- 销售额为飞瓜实数返回的预估销售额文本解析结果。
- 当前只覆盖美妆、婴童洗护两个类目。
- 若品牌未进入对应分段榜单，该分段会显示缺失，不代表品牌真实销售额为 0。
- 黑马判断基于上一年度规模、本年度增速、排名提升和趋势覆盖率，适合作为报告候选清单，关键结论仍建议人工复核。
